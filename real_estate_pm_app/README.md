# Real Estate Engineering Consultancy Project Management App

This is a project management application tailored for real estate engineering consultancies.

## Setup and Running

1.  **Clone the repository (if applicable).**
2.  **Create a virtual environment:**
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # On Windows use `.venv\Scripts\activate`
    ```
3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
4.  **Run the application:**
    ```bash
    export FLASK_APP=app  # On Windows use `set FLASK_APP=app`
    export FLASK_ENV=development # Optional: for development mode
    flask run
    ```
    The application will typically be available at `http://127.0.0.1:5000/`.
